# Textify 1.1.0 for macOS

Textify turns speech into text locally on your Mac. Hold your dictation
trigger, speak, then release it to insert the transcription into the app you're
using.

## Download

Download the Apple Silicon DMG and its matching `.sha256` file from the Assets
section below.

### System requirements

- macOS 14 (Sonoma) or later, Apple Silicon (M1 or later). Intel Macs are not
  supported.
- Microphone and Accessibility permissions
- A network connection to download Textify and your chosen model. Dictation is
  offline after setup.

## What's included

- Local transcription with Whisper, Core ML, MLX, transcribe.cpp, and
  sherpa-onnx runtime support
- A signed 42-entry model catalog and signed revocation baseline bundled with
  the app
- Native onboarding, model management, configurable dictation language,
  microphone selection, four trigger choices, and text insertion
- Custom vocabulary, phrase replacements, and optional MossFormer2 voice
  cleaning
- Open-source licenses and notices inside the app bundle

Model weights aren't bundled. Textify downloads only the model you choose and
verifies the download's byte size and SHA-256 against the signed catalog before
activation.

## Install and open Textify

1. Download `Textify-1.1.0-unsigned-preview.1-arm64.dmg` and
   `Textify-1.1.0-unsigned-preview.1-arm64.dmg.sha256`.
2. Open Terminal in your download directory and verify the DMG:

   ```bash
   shasum -a 256 -c Textify-1.1.0-unsigned-preview.1-arm64.dmg.sha256
   ```

3. Open the DMG and drag Textify to Applications.
4. Open Textify from Applications.

### First-launch note

The DMG is unsigned and unnotarized. The app is ad-hoc signed, not Developer ID
signed, with Hardened Runtime. It disables macOS library validation so its
separately ad-hoc-signed native libraries can load without a shared Developer
ID team identity. Because of this, macOS may block the first launch.

If you trust this repository and the verified download, open **System Settings
→ Privacy & Security**, find the blocked Textify message, select **Open
Anyway**, and confirm. Do not disable Gatekeeper or remove quarantine
attributes system-wide. Apple documents this scoped approval in its
[guide to opening an app from an unknown developer](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).

## Start dictating

1. Grant Microphone and Accessibility access during onboarding.
2. Choose and download a speech model.
3. Hold the configured trigger, speak, then release it. Right Command is the
   default trigger.

## Privacy

Textify processes dictation on your Mac and doesn't save recorded audio or keep
a dictation history. It has no accounts, analytics, or crash reporting. Network
access is used for app and model downloads, not transcription.
