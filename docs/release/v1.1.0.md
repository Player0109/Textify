# Textify 1.1.0

> Release-body candidate. Publish this text only after the referenced DMG has
> passed Developer ID signing, notarization, stapling, checksum, and manual
> release-evidence gates.

Textify 1.1.0 is the first public release of the native, offline dictation app
for Apple Silicon Macs.

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon (M1 or later); Intel Macs are not supported
- Microphone and Accessibility permissions
- Network access for the app and the model download you choose; dictation is
  offline after installation

## Install

1. Download `Textify-1.1.0-arm64.dmg` and
   `Textify-1.1.0-arm64.dmg.sha256` below.
2. In Terminal, from the download directory, run:

   ```bash
   shasum -a 256 -c Textify-1.1.0-arm64.dmg.sha256
   ```

3. Open the DMG, drag Textify to Applications, and launch it from Applications.
4. Complete permission setup and install a transcription model.

The DMG is Developer ID signed, notarized by Apple, and stapled. Automatic
updates are deferred in Textify 1.1; install future versions from GitHub
Releases.

## Highlights

- Hold a configurable trigger to record, then insert one locally transcribed
  final result into the focused text field.
- Choose from a bundled signed catalog of 39 transcription models and three
  optional voice-cleaning models.
- Run supported Whisper, Parakeet, Paraformer, ReazonSpeech, SenseVoice,
  Qwen3-ASR, Nemotron, Granite Speech, Voxtral, MOSS, and related routes through
  local Apple Silicon runtimes.
- Verify every downloaded model file against signed size and SHA-256 metadata
  before it can become active.
- Configure model, language, trigger, and floating recording-icon placement
  from the native Settings window. Textify 1.1 records from the system-default
  microphone.

Textify has no accounts, analytics, crash reporter, cloud ASR, or transcript
history. See the
[privacy statement](https://github.com/Player0109/Textify/blob/v1.1.0/PRIVACY.md),

for details.
