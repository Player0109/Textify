# Textify desktop 0.2.0 Preview 23

This is the Electron desktop preview for macOS, Windows, and Linux. It is
separate from the older native macOS `v1.1.0-unsigned-preview.1` release.

**Draft: not ready for publication.** The macOS Developer ID certificate is
installed. Local notarization credentials must be configured, the final Mac
DMG must pass signing/notarization checks, and the exact release commit must
pass all three desktop CI jobs before these notes are finalized. Physical-device QA
remains incomplete; see the limitations below.

## Downloads

| Platform | Installer | Requirements |
| --- | --- | --- |
| macOS | `Textify-0.2.0-preview.23-mac-arm64.dmg` | macOS 14+, Apple Silicon, Metal |
| Windows | `Textify-0.2.0-preview.23-win-x64.exe` | Windows x64, hardware Vulkan GPU and compatible driver |
| Linux | `Textify-0.2.0-preview.23-linux-x86_64.AppImage` or `Textify-0.2.0-preview.23-linux-amd64.deb` | Linux x64, hardware Vulkan GPU and compatible driver |

Installers will be attached only after their respective verification completes.
The Mac download is intended to be Developer ID signed and notarized; that
status has not yet been verified for this candidate. Windows and Linux
installers are unsigned. Windows may show a SmartScreen warning.

Verify downloads against the final `SHA256SUMS.txt`. Speech models download
separately from the in-app catalog and are checked before use. CPU-only
inference is not supported.

## Included in this desktop preview

- Hold-to-dictate with local GPU transcription, a floating recording bar,
  vocabulary, replacement pairs, microphone selection, and app exclusions
  where supported by the desktop.
- A model browser with verified downloads. Whisper is available on all three
  platforms; Confucius4-R2T2, Parakeet, and Qwen3-ASR currently use Metal on
  Apple Silicon. Confucius supports an in-memory live preview.
- An Activity page showing daily, weekly, and monthly numeric usage totals.
  It retains no dictated text, audio, or destination app with those totals.
- Guided macOS Accessibility setup and manual GitHub Release updates.

## Installation

On macOS, open the DMG, drag Textify into Applications, and grant Microphone
and Accessibility access when prompted. The default trigger is Right Command.

On Windows, run the x64 installer. The default trigger is Right Control.

On Linux, install the Debian package or run the AppImage. AppImage mounting
requires FUSE. Linux uses Copy and manual paste; Wayland global shortcuts
depend on the desktop's GlobalShortcuts portal, and app exclusions are
unavailable on Wayland.

Open Transcription models, install a supported model, then try a short
dictation. Audio and dictated text are processed locally. There are no
automatic app updates; install a later release manually.

## Verification and limitations

The current local source passed TypeScript, 118 tests, a production build,
and isolated Electron UI smoke checks on the maintainer Mac. The final CI run
and artifact verification results will be recorded before publication.
Whisper recognition of the public test fixture also passed on the maintainer's
Apple M4 Max using Metal and the exact verified model artifact.

Hosted CI checks package creation, installation, app launch, and refusal to
fall back to CPU on GPU-less runners. It does not prove real microphone,
hardware-GPU recognition, or physical global-shortcut behavior.

The owner has tested macOS microphone and text insertion. Windows and Linux
remain untested on physical hardware. Real Windows Vulkan recognition, Linux
hardware/Wayland behavior, and final signed Mac installer and second-Mac
fresh-install/update verification remain pending in
[the desktop QA checklist](../../electron/MANUAL_QA.md). This candidate must
remain a preview while those checks are incomplete.
