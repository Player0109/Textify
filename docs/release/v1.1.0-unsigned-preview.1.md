# Textify 1.1.0 - Unsigned Preview 1

> **Unsigned pre-release:** this DMG is not Developer ID signed or notarized by
> Apple. macOS will block its first launch until you approve Textify manually.
> This is not the future `v1.1.0` production release.

Textify is a native, offline dictation app for Apple Silicon Macs. This preview
is available now for people who are comfortable testing an open-source,
unnotarized macOS app while the Developer ID release is deferred.

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon (M1 or later); Intel Macs are not supported
- Microphone and Accessibility permissions
- Network access to download the app and your chosen model; dictation is
  offline after installation

## Install

1. Download `Textify-1.1.0-unsigned-preview.1-arm64.dmg` and
   `Textify-1.1.0-unsigned-preview.1-arm64.dmg.sha256` below.
2. In Terminal, from the download directory, verify the downloaded bytes:

   ```bash
   shasum -a 256 -c Textify-1.1.0-unsigned-preview.1-arm64.dmg.sha256
   ```

3. Open the DMG and drag Textify to Applications.
4. Try to open Textify from Applications. The expected macOS warning says that
   Apple cannot verify the developer.
5. If you trust this repository and download, open **System Settings → Privacy
   & Security**, find the blocked Textify message, choose **Open Anyway**, and
   confirm.

Do not disable Gatekeeper or remove quarantine attributes system-wide. Apple's
[unknown-developer guidance](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
describes this scoped exception. Building directly from the tagged source is
the free alternative to downloading this binary.

## What is included

- The full arm64 Textify app with its bundled, signed 42-entry model catalog
  and signed revocation baseline
- Local Whisper, Core ML, MLX, transcribe.cpp, and sherpa-onnx runtime support
- Native onboarding, model management, configurable dictation language,
  microphone selection, hotkeys, offline transcription, and text insertion
- Required open-source licenses and notices inside the app bundle

Model weights are not bundled. Textify downloads only the model you choose and
verifies its signed size and SHA-256 metadata before activation.

## Preview limitations

- The app uses an ad-hoc code signature needed for local Apple Silicon
  execution. That signature checks bundle consistency but does not establish a
  verified publisher identity.
- This preview disables macOS library validation so its separately ad-hoc-signed
  native libraries can load without a shared Developer ID team identity. The
  future production build will sign every library with Developer ID and will
  not use this exception.
- The DMG is unsigned and unnotarized. Gatekeeper rejection on first launch is
  expected. Because ad-hoc builds have changing code identities, you may need
  to remove and re-add Textify under Accessibility after a later preview
  update.
- Remaining production conformance and final-candidate evidence are tracked in
  [issue #31](https://github.com/Player0109/Textify/issues/31) and
  [issue #25](https://github.com/Player0109/Textify/issues/25).
- Automatic updates are deferred; replace the app manually for a later build.

The `.sha256` file detects transfer corruption and confirms that your DMG
matches the bytes uploaded to this release. It is not a substitute for a future
Developer ID signature and Apple notarization.
